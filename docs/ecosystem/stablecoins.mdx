# Stablecoins on Kaia

Kaia is building out infrastructure and partnerships focused on stablecoins, positioning the network as a settlement layer for payments and real-world asset flows.

## Why Kaia is focusing on stablecoins

- **Payments and remittances**: Stablecoins on Kaia enable fast, low-cost transfers that can settle near-instantly compared to traditional rails.
- **On-chain liquidity**: A reliable stablecoin base is a prerequisite for DeFi, trading, and merchant use cases to grow on the network.
- **Regional reach**: Kaia's ecosystem spans messenger-integrated wallets with large user bases, making stablecoins a practical entry point for mainstream users who are not yet holding volatile crypto assets.

## What this means for developers

- Stablecoin contracts on Kaia follow the same account, transaction, and smart contract model as any other token — see [Get Started](/docs/build/get-started/get-started) for the basics.
- When integrating a stablecoin, check the issuer's official contract address and decimals before wiring up a dApp; do not assume parity with equivalents on other chains.
- Testnet faucets distribute test KAIA for gas, not test stablecoins — stablecoin test liquidity, where available, is provided separately by the issuer.

## Next steps

- Review the issuer-specific docs for the stablecoin you plan to integrate.
- Continue to the [Get Started](/docs/build/get-started/get-started) guide to set up a wallet and testnet environment before building.
